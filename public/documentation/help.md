The Hello World widget shows a single line of text on the board. It is a simple label you can use for titles, short notes, or greetings.

You can change the text, its color, its font, and its alignment. Everyone on the board sees the same text and style, and changes show up for everyone right away.

## How to use

### Add a label

1. Add the widget to the board. The settings dialog opens automatically.
2. Type your text in **Text to display** and save.
3. Use the widget bar to pick a text color, a font, and an alignment.
4. Resize the widget so the whole text fits.

### Limitations

- The text is shown on a single line at a fixed size. Text that is longer than the widget is cut off at the edge instead of wrapping or shrinking.
- The background of the widget is always transparent.

## Widget bar

The widget adds a text color, a font, and a text alignment button to the widget bar.

### Text color

Opens a color picker for the text. The colors come from the text color palette. Transparent is not offered. The default color is the text color set by your organization.

### Font

Opens a list of fonts for the text. Pick a font to change it for everyone on the board.

### Text alignment

Opens a small menu with **Align left**, **Align center**, and **Align right**. It sets where the text sits inside the widget. Alignment is easiest to see when the widget is wider than the text. The default is left, unless your organization set a different default.

## Settings

Open the settings dialog from the settings button in the widget bar.

### Text to display

The text that is shown in the widget. The default is "Hello Alleo!", unless your organization set a different default text. Keep it short, because the text stays on one line.

## Tips

- If the end of your text is missing, make the widget wider.
- Use center alignment together with a wide widget to make a centered title.
